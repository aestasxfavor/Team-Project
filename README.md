# Meowbellion

## 프로젝트 소개

SFML과 C++을 활용해 제작한 3인 팀 프로젝트입니다.

몰려오는 적을 처치하고, 웨이브마다 능력을 선택해 캐릭터를 성장시키는 웨이브 기반 로그라이크 게임입니다.

## 게임 흐름

1. 플레이어를 조작해 몰려오는 적과 전투합니다.
2. 적을 처치해 경험치를 획득하고 캐릭터를 성장시킵니다.
3. 웨이브가 종료되면 능력 선택 화면이 나타납니다.
4. 선택한 능력이 플레이어에게 적용됩니다.
5. 다음 웨이브를 진행하며 최대한 오래 생존합니다.
6. 플레이어가 사망하면 게임 오버 화면으로 전환됩니다.

## 주요 기능

* 플레이어 이동 및 전투
* 웨이브 기반 적 생성
* 적 처치 및 경험치 획득
* 레벨 및 능력 성장
* 웨이브 종료 후 능력 선택
* 체력, 경험치, 레벨, 웨이브 HUD
* 현재 적용된 능력 정보 표시
* 게임 상황별 효과음
* 게임 오버 및 재시작
